# Sources and scope

Jouri (formerly Motri) is an independent prototype, not a Hajwala mode and not an AR-Aboden dependency.

## RC vehicle reference

- Source: https://github.com/icurtis1/raycast-vehicle
- Reviewed revision: `f9d2457e94c18f71a8eca5884c68d943b6f1e9e5`
- Source file: `src/Vehicle.js`
- MIT, Copyright (c) 2026 Ian Curtis. The full MIT terms are included in LICENSE.

`src/vehicle.js` adapts the donor's lifted rectangular chassis, four-ray wheel
layout and suspension parameters, rear-axle force sign, steering sign, chassis
inertia stabilization, axle-load anti-wheelie limiter, and chassis-local wheel
transform synchronization. `src/visuals.js` adapts its procedural placeholder
body/wheel organization. The donor is not a runtime dependency.

Changes: a separate dependency-free, signed target-speed controller; analogue
mobile input, stop-before-reverse, precision mode, cabin collision, explicit
fixed stepping, simplified replaceable visuals, and an original test arena.
The donor's 20 MB vehicle models, environment, audio, jump/boost, tire marks,
menus and postprocessing stack are not included.

## Runtime dependencies (pinned)

- Three.js 0.185.1, MIT: https://github.com/mrdoob/three.js
- cannon-es 0.20.0, MIT: https://github.com/pmndrs/cannon-es
- GLTFLoader comes from the same pinned Three.js release.

These libraries are loaded from jsDelivr in the browser; the first load needs
internet access. Library code is not bundled in this archive. No telemetry,
account login, external model files, or camera access is used.

No Lost Host code, names, story, music or assets are included. All visible
placeholder geometry in this prototype is generated by code.
