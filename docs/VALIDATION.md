# التحقق من نسخة موتري الأولى

## قبل الرفع

- نجحت 16 حالة لمنطق التحكم والخطوة الزمنية الثابتة في Node.
- نجح فحص تركيب ملفات JavaScript وتطابق عناصر الواجهة.
- لم يمكن تنزيل المكتبات في بيئة العمل المحلية بسبب تعذر الوصول إلى CDN.

## التحقق على GitHub

ينفذ Workflow `Motri checks` الاختبارات على المكتبات المثبتة: الاستقرار على أربع عجلات، التقدم والفرملة والاستعادة، الرجوع، ودفع صندوق. غياب المكتبة يفشل الاختبار ولا يتحول إلى SKIP.

اختبار Chromium يفتح الصفحة بكود اللعبة ومحركي Three.js وcannon-es الحقيقيين، باستخدام نسخ المكتبات المثبتة المطابقة للـimport map بدل طلب CDN في الاختبار فقط. يتحقق من بدء العرض والقيادة والفرامل والجويستك بلمستين والواجهتين الطولية والعرضية. لقطات الشاشة تحفظ كأثر للاختبار. راجع نتيجة تشغيل Workflow الخاصة بالـcommit المطلوب، لا تعد وجود الاختبارات إثباتًا لنجاحها.

## حدود التحقق

المحاكاة في Chromium واختبارات Node لا تعادل اختبار Safari أو جهاز iPhone حقيقي. لم يُختبر موديل GLB خارجي بعد. النسخة الأولية تحتاج تجربة القيادة على الجهاز قبل اعتماد المرحلة والسرعات.
