# موتري — MOTRI

[افتح اللعبة](https://3wasfnjd.github.io/motri/)

مشروع مغامرة مستقل بسيارة صغيرة لمتصفح الجوال؛ لا يعتمد على هجولة أو AR-Aboden. النسخة الحالية ساحة اختبار قيادة وليست مراحل المغامرة النهائية.

## السيارة

تم توصيل ملف المستخدم `models/gmc_sierra_work_truck.glb` بدل السيارة البرمجية. يفصل `src/gmc.js` العجلات الأربع من المكونات المنفصلة هندسيًا داخل المجسم المدمج، ويحافظ على الخامات وUV والمثلثات الأصلية، مع استبعاد أرضية العرض الجاهزة. تضبط نقاط التعليق وأبعاد التصادم وفق الموديل، بدل تمديده ليلائم السيارة السابقة.

الملف الأصلي لم يُضغط أو يُعدّل. إعداد الموديل في `models/vehicle.json`. يكتمل تحميله قبل تفعيل زر البداية؛ فشل التحميل يظهر تحذيرًا واضحًا مع إتاحة السيارة المؤقتة.

## التحكم والسرعة

المقود يسار الشاشة. يمينًا متحكم واحد للبنزين واتجاه الحركة: للأعلى تقدم وللأسفل رجوع، ومقدار السحب يحدد الدعسة. المنتصف ورفع الإصبع يعيدان المحايد. عند عكس الاتجاه أثناء الحركة يفرمل النظام أولًا. الفرامل مستقلة ولها الأولوية؛ المقود والدعسة يعملان بلمستين مستقلتين.

حد التقدم الافتراضي **14** بدل **10**، والرجوع **8.4** بدل **6**. قوة المحرك العادية **1600** بدل **1100**، مع استجابة متدرجة. الأرقام بوحدات المحاكاة وليست كم/س. الإعدادات تسمح بحد تقدم من 4 إلى 20، والرجوع 60% منه. القيادة الدقيقة تبقى 1.5 وبقوة 750 للألغاز.

محرك الفيزياء cannon-es: هيكل وكابينة وأربع نقاط Raycast. بقيت طريقة التحكم والكاميرا ونظام الفرملة قرب الصفر كما هي.

الكمبيوتر: WASD أو الأسهم، Space فرامل، R إعادة السيارة، P قيادة دقيقة، Esc إيقاف.

## التشغيل والاختبارات

```sh
npm install --ignore-scripts --no-audit --no-fund
npm start
npm test
npm run check
npm run test:physics
npm run build
```

GitHub Pages: `main` والجذر. المكتبات من CDN بإصدارات مثبتة؛ تحتاج إنترنت. اختبارات GMC تستخدم الملف المرفوع فعليًا لفصل الهندسة وقياس السرعة والفرملة والرجوع والدفع والمنحدر. اختبار Chromium يحمّل خامات GLB الأصلية ويتحقق من اختفاء كل الأجزاء المؤقتة ومن التحكم اللمسي بثلاثة مقاسات. اختبار Node للهندسة لا يفك الصور؛ فحص الخامات ضمن اختبار المتصفح.

النسخة الأحادية التي يولدها البناء تبقى بسيارة برمجية ولا تدمج GLB داخل HTML؛ النسخة المنشورة متعددة الملفات هي نسخة GMC.
