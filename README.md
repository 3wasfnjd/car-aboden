# موتري — MOTRI

[افتح تجربة القيادة](https://3wasfnjd.github.io/motri/)

قاعدة مستقلة للعبة مغامرة بسيارة لعبة على متصفح الجوال. الاسم والموديل مؤقتان. لا تعتمد على هجولة أو AR-Aboden.

## النسخة الأولى

سيارة خفيفة مولّدة بالكود، هيكل تصادم وكابينة وأربع نقاط تعليق Raycast باستخدام cannon-es. تحكم لمسي متدرج، تقدم ورجوع، فرامل ووضع قيادة دقيقة. ساحة اختبار تحتوي منحدرًا ومنصة وممرًا وصناديق قابلة للدفع. الهدف الأول: دفع الصندوق البرتقالي إلى العلامة الخضراء.

الكاميرا قابلة لتبديل الزاوية، ويمكن ضبط الجودة وإعادة السيارة أو الساحة. الحفظ يقتصر على نقطة بداية داخل المنطقة الخالية؛ ليس نظام حفظ قصة. لا يوجد AR أو VR أو لعب جماعي في هذه النسخة.

## التشغيل والاختبار

```sh
npm start
# http://localhost:5173
npm test
npm run check
npm install --ignore-scripts --no-audit --no-fund
npm run test:physics
npm run build
```

المتصفح يحمّل Three.js 0.185.1 وcannon-es 0.20.0 من CDN؛ يحتاج الإنترنت. اختبارات الفيزياء تتطلب تثبيت المكتبة الحقيقية، وتفشل عند غيابها بدل احتساب الاختبار ناجحًا. GitHub Actions يشغّل اختبارات التحكم والفيزياء وفحص المصدر والبناء واختبار فتح اللعبة في Chromium.

النشر: GitHub Pages من `main` / الجذر، والملف الرئيسي `index.html`. لا حاجة لرفع ZIP أو `node_modules` أو `dist` إلى الجذر.

## التحكم

الجوال: أعلى/أسفل الجويستك للتقدم/الرجوع؛ يمين/يسار للتوجيه؛ مقدار السحب يحدد السرعة. زر الفرامل بالضغط المستمر، وزر القيادة الدقيقة للتبديل.

الكمبيوتر: WASD أو الأسهم، Space فرامل، R إعادة السيارة، P قيادة دقيقة، Esc إيقاف مؤقت.

## الموديلات

راجع [مواصفات الموديلات](docs/MODELS_AR.md). إعداد الاستيراد `models/vehicle.json` معطل حتى توفير موديل مناسب؛ لا يوجد ملف GLB ناقص مطلوب لبدء التجربة. يمكن تبديل الهيكل والعجلات مع إبقاء المتحكم منفصلًا عن الشكل.
