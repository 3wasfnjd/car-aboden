# جود — JOOD

## فكرة المستودع
تجربة قيادة لشاحنة ورد صغيرة على متصفح الجوال، تتيح وضعها وقيادتها داخل المكان بالواقع المعزز، ضمن مشروع مغامرة مستقل قيد التطوير.

## الخدمات والمزايا
- قيادة شاحنة الورد بفيزياء عجلات وتعليق وتحكم باللمس.
- وضع واقع معزز وساحة اختبار قيادة دون كاميرا.
- لعب جماعي حتى أربعة لاعبين في الغرفة، مع أسماء على الشاحنات ورسائل قصيرة.
- إضاءة وزينة وبتلات ورد وموسيقى هادئة قابلة للإيقاف.
