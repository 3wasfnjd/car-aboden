# موتري — MOTRI

[افتح تجربة القيادة](https://3wasfnjd.github.io/motri/)

قاعدة مستقلة للعبة مغامرة بسيارة لعبة على متصفح الجوال. الاسم والموديل مؤقتان. لا تعتمد على هجولة أو AR-Aboden.

## النسخة الأولى

سيارة خفيفة مولّدة بالكود، هيكل تصادم وكابينة وأربع نقاط تعليق Raycast باستخدام cannon-es. مقود يسار الشاشة وبنزين وفرامل منفصلان يمينها، تقدم ورجوع ووضع قيادة دقيقة. ساحة اختبار تحتوي منحدرًا ومنصة وممرًا وصناديق قابلة للدفع. الهدف الأول: دفع الصندوق البرتقالي إلى العلامة الخضراء.

الكاميرا قابلة لتبديل الزاوية، ويمكن ضبط الجودة وإعادة السيارة أو الساحة. الحفظ يقتصر على نقطة بداية داخل المنطقة الخالية؛ ليس نظام حفظ قصة. لا يوجد AR أو VR أو لعب جماعي في هذه النسخة.

## التشغيل والاختبار

```sh
npm start
# http://localhost:5173
npm test
npm run check
npm install --ignore-scripts --no-audit --no-fund
npm run test:physics
npm run build
```

المتصفح يحمّل Three.js 0.185.1 وcannon-es 0.20.0 من CDN؛ يحتاج الإنترنت. اختبارات الفيزياء تتطلب تثبيت المكتبة الحقيقية، وتفشل عند غيابها بدل احتساب الاختبار ناجحًا. GitHub Actions يشغّل اختبارات التحكم والفيزياء وفحص المصدر والبناء واختبار فتح اللعبة في Chromium، ومنها لمس المقود والبنزين والفرامل معًا، وأولوية الفرملة، والتقدم والرجوع، وقفل تغيير الاتجاه أثناء الحركة، وإلغاء اللمس وفقدان التركيز.

النشر: GitHub Pages من `main` / الجذر، والملف الرئيسي `index.html`. لا حاجة لرفع ZIP أو `node_modules` أو `dist` إلى الجذر.

## التحكم

- **المقود يسارًا:** اسحبه أفقيًا يمينًا أو يسارًا للتوجيه فقط، دون أي دعسة تلقائية. يعود للوسط عند تركه.
- **البنزين يمينًا:** اضغط باستمرار؛ أسفل الدواسة سرعة خفيفة، واسحب لأعلى لزيادتها. عند رفع الإصبع تنقطع الدعسة ويعمل تباطؤ المحرك الحالي.
- **الفرامل يمينًا بجوار البنزين:** ضغط مستمر للتوقف، وتتغلب على البنزين عند الضغط عليهما معًا. لا تتحول الفرامل إلى رجوع.
- **D / R:** تقدم أو رجوع. تغيير الاتجاه لا يُقبل أثناء الحركة أو مع استمرار ضغط البنزين؛ توقف أولًا.
- **قيادة دقيقة:** تحد السرعة قرب العقبات. لم تتغير فيزياء السيارة أو حد السرعة أو الكاميرا مع فصل التحكم.

تعمل أدوات القيادة بلمسات مستقلة؛ رفع إصبع المقود لا يقطع البنزين. يُلغى الإدخال عند الإيقاف، وفتح الإعدادات، وفقدان التركيز أو تغيير حجم الشاشة لمنع بقاء دواسة مضغوطة.

الكمبيوتر: WASD أو الأسهم، Space فرامل، R إعادة السيارة، P قيادة دقيقة، Esc إيقاف مؤقت. W/S يحددان اتجاه الحركة مباشرة. يمكن تشغيل دواسة مركّز عليها بلوحة المفاتيح بالضغط المستمر على Enter أو Space.
