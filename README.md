# موتري — MOTRI

[افتح اللعبة](https://3wasfnjd.github.io/motri/)

مشروع مغامرة مستقل بسيارة صغيرة لمتصفح الجوال؛ لا يعتمد على هجولة أو AR-Aboden. النسخة الحالية ساحة اختبار قيادة وليست مراحل المغامرة النهائية.

## السيارة الحالية: تجربة الموديل الأحمر

الموديل المستخدم الآن هو `models/gmc_sierra_red_light.glb` الذي رفعه المستخدم: هيكل أحمر وأربع عجلات منفصلة. يربطه `prepareRedGmcModel` في `src/models.js` بنقاط التعليق والتوجيه والدوران، مع الحفاظ على نسب المجسم وخاماته؛ لم يتغير ملف GLB نفسه.

**الموديل الأول `models/gmc_sierra_work_truck.glb` موجود ولم يُحذف أو يُعدّل.** بقي محوّله `src/gmc.js` واختباراته، وحُفظت نسخة مطابقة من إعداده السابق في `models/vehicle-original.json`. للعودة إليه لاحقًا انسخ محتوى هذا الإعداد إلى `models/vehicle.json`. لا تُحمّل اللعبة الموديلين معًا؛ تُحمّل المحدد في الإعداد فقط.

يكتمل تحميل السيارة قبل تفعيل زر البداية. فشل التحميل يظهر تحذيرًا واضحًا مع إتاحة السيارة المؤقتة. الموديل الأحمر للتجربة وليس اختيارًا نهائيًا.

## التحكم والسرعة

المقود يسار الشاشة. يمينًا متحكم واحد للبنزين واتجاه الحركة: للأعلى تقدم وللأسفل رجوع، ومقدار السحب يحدد الدعسة. المنتصف ورفع الإصبع يعيدان المحايد. عند عكس الاتجاه أثناء الحركة يفرمل النظام أولًا. الفرامل مستقلة ولها الأولوية؛ المقود والدعسة يعملان بلمستين مستقلتين.

لم تتغير إعدادات القيادة عند تبديل الموديل: حد التقدم **14** والرجوع **8.4**، وقوة المحرك العادية **1600**. الأرقام بوحدات المحاكاة وليست كم/س. الإعدادات تسمح بحد تقدم من 4 إلى 20، والرجوع 60% منه. القيادة الدقيقة تبقى 1.5 وبقوة 750 للألغاز.

محرك الفيزياء cannon-es: هيكل وكابينة وأربع نقاط Raycast. تتوافق مواقع العجلات وحدود التصادم مع الموديل المختار دون تغيير الكاميرا أو استجابة التحكم أو الفرملة.

الكمبيوتر: WASD أو الأسهم، Space فرامل، R إعادة السيارة، P قيادة دقيقة، Esc إيقاف.

## الواقع المعزز (AR)

المسار `ar/` (مثل `https://3wasfnjd.github.io/motri/ar/`) يعرض السيارة وحدها في المكان الحقيقي عبر كاميرا الجوال، دون أرضية أو ساحة اختبار أو ظل. يقرأ الموديل المحدد في `models/vehicle.json`، فأي تعديل على السيارة يظهر فيه تلقائيًا. يعتمد على `model-viewer` 4.3.1 من CDN: أندرويد عبر WebXR أو Scene Viewer، وآيفون عبر Quick Look، حيث يحوّل الصفحة GLB إلى USDZ تلقائيًا. الحجم الافتراضي حقيقي بالمتر، نحو 5.3 م طولًا، ويمكن تصغيره بإصبعين. على الكمبيوتر تظهر معاينة ثلاثية الأبعاد فقط.

## التشغيل والاختبارات

```sh
npm install --ignore-scripts --no-audit --no-fund
npm start
npm test
npm run check
npm run test:physics
npm run build
```

GitHub Pages: `main` والجذر. المكتبات من CDN بإصدارات مثبتة؛ تحتاج إنترنت. اختبارات الموديلات تستخدم ملفي GLB الفعليين، وتتحقق من بقاء بايتاتهما دون تغيير ومن حركة العجلات والفرملة والرجوع والدفع والمنحدر. يتحقق اختبار Chromium من تحميل الأحمر فقط، وصحة خاماته، واختفاء الأجزاء المؤقتة، والتحكم اللمسي بثلاثة مقاسات. اختبار Node للهندسة لا يفك الصور؛ فحص الخامات ضمن اختبار المتصفح.

النسخة الأحادية التي يولدها البناء تبقى بسيارة برمجية ولا تدمج GLB داخل HTML؛ النسخة المنشورة متعددة الملفات تستخدم الموديل المحدد في الإعداد.
